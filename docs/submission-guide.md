# Передача результата MadDevs

Кандидат v1.0 подготовлен для проверки владельцем. Успешные технические тесты не означают фактическую сдачу. Письмо работодателю агент не отправляет.

| Шаг владельца | Что подготовлено | Что осталось |
|---|---|---|
| Проверить результат | Русская README, итоговые таблицы, тесты, демонстрационный сценарий | Посмотреть приложение и принять ограничения |
| Утвердить эссе | Черновик ровно из 10 предложений | Проверить личную формулировку и явно одобрить |
| Проверить AI disclosure | `solana 6.1 - medium`, буквально со слов владельца | При желании уточнить написание, без догадок об API model ID |
| Выбрать способ проверки кода | Ветка `codex/russian-submission`, реальные commits и CI | Дать точную ссылку на проверенный commit; main может оставаться ранней версией |
| Предоставить доступ | Репозиторий приватный | Дать работодателю read access и проверить его с аккаунта проверяющего |
| Решить вопрос PR/merge | Реальные PR #1–3, тексты следующих подготовлены | Отдельно разрешить нужные действия; PR не обязательный пункт письма MadDevs |
| Передать материалы | Код, инструкции, AI-журнал, промпты, тесты, ограничения и план | Лично отправить до 26 октября 2026 и сохранить подтверждение |

## Комплект

Исходники, lockfiles, Compose и миграции 0001–0006; [README](../README.md); [архитектура](architecture.md) и [решения](decisions.md); [матрица приёмки](phase7-final-acceptance.md); [итоговый отчёт](OWNER_FINAL_REPORT_RU.md); [журнал](development-log.md), [промпты](prompts/README.md), raw artifacts; [демонстрация](demo-script.md), [контрольный список](release-checklist.md), [AI disclosure](ai-development.md), [эссе](essay.md) после личного утверждения.

Полный экспорт сессии не заявляется: работодатель допускает журнал решений или разработки. Проект создан с нуля, без чужого шаблона приложения; сторонние библиотеки указаны в README. Лицензию выбирает владелец. Не передавайте `.env`, пароли, токены, пользовательскую базу или сырые файлы с секретами.

## Безопасная передача

Сначала проверьте точный SHA и его Actions, затем доступ к ветке и воспроизводимость запуска. Не выполняйте merge только ради красивой истории: сохранённая последовательность commits и существующие PR уже доступны проверяющему. Не меняйте приватность и не удаляйте volumes. Итоговый статус меняется на SUBMITTED только после настоящей отправки владельцем.
